Create a standard-library Python CLI linkcheck.py <folder>.

Recursively scan .md files and extract Markdown [text](url) and file:///... links.

Validate:

* local/file links: target must exist relative to the current Markdown file;
* HTTP(S): HEAD, fallback GET, handle errors/timeouts and status codes.

Print a clean colored/table-like console report listing broken links, source files, and HTTP/status/error reason.

Exit 1 if broken links exist, otherwise 0.
