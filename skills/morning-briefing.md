# Утренняя сводка (Тип B: последовательность действий)

Запускается по просьбам вида «утренняя сводка», «что там на сегодня»,
«брифинг», «доброе утро». Четыре шага, строго по порядку, по одному вызову
инструмента за шаг.

**Шаги 1–3 — это команды, которые надо выполнить инструментом `exec`.**
Ни дату, ни погоду, ни дела ты не знаешь заранее: без вызова у тебя нет
этих данных. Шаблон из шага 4 заполняется только тем, что вернули команды.

## Шаг 1. Дата и время

```
date "+%A, %d %B %Y, %H:%M"
```

Нужно, чтобы отобрать дела именно на сегодня: своей датой ты не располагаешь.

## Шаг 2. Погода

```
curl -s "https://wttr.in/Minsk?0&T&M&lang=ru"
```

Город по умолчанию Анталья; если пользователь назвал другой — подставь его.
Никаких других скиллов для этого шага открывать не нужно.

## Шаг 3. Дела на день

Пропускать этот шаг нельзя: пока ты не прочитал файл, ты не знаешь,
есть ли сегодня дела, и написать «дел нет» не имеешь права.

```
cat data/agenda.md
```

Команда вернула строки — шаг закончен, ничего больше по нему не запускай.
Вернулся `exit code: 1` — файла нет: тогда одной строкой скажи в сводке, что
список дел недоступен, и переходи к шагу 4. Обходных путей не ищи и встреч
не выдумывай.

Из файла бери только строки с сегодняшней датой из шага 1. Строки прошедших
дней в сводку не идут.

## Шаг 4. Итог — последнее действие

Шаги 1–3 позади, все данные у тебя перед глазами. Инструменты здесь больше
не нужны: ты просто пишешь сообщение пользователю, и на этом задача закончена.

Три-четыре предложения живым языком. Начни с дня недели и даты из шага 1.
Скажи о погоде из шага 2 — температура, ощущается, осадки, ветер — и добавь
практический совет: зонт, тёплая куртка, ничего особенного. Перечисли дела
из шага 3 маркерами «• время — дело». Закончи одной строкой о том, на что
сегодня обратить внимание.

Дел не нашлось или какой-то шаг провалился — скажи об этом одной строкой,
остальное всё равно допиши. Плейсхолдеров, скобок и пометок «вставить сюда»
в готовом сообщении быть не должно.

## Правила

- Не более одного вызова инструмента за шаг: сначала результат, потом решение.
- Каждый шаг делается один раз. Уже выполненную команду не повторяй.
- Шаг провалился — не бросай сводку: отметь этот пункт недоступным
  и доделай остальные.
- Не показывай пользователю сырой вывод команд и не пересказывай ASCII-картинки.
